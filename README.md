# SOL’n WORKS — Portfolio

Hey there! Welcome to the repository for my personal portfolio. This site is my home base for sharing the software and design projects I've worked on, my technical skills, my certificates, and how to get in touch with me.

If you're visiting the live site, you can explore what I've built, browse design artwork and certificates, preview my resume right in a pop-up modal, or download a copy to keep.

## Technologies

- React 18
- Vite 5
- JavaScript, HTML, and CSS
- Native HTML dialogs for resume and image previews

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

To create and preview a production build:

```bash
npm run build
npm run preview
```

## Project structure

- `src/components/` — page sections and interactive components
- `src/data.js` — portfolio content, projects, skills, certificates, and links
- `src/styles.css` — site styles and responsive layouts
- `public/` — resume, case study, profile, certificate, and project assets
